# Logotipo RAFAELIA/RafPolimata — ASCII 60 colunas

Arte ASCII com largura fixa de 60 colunas. A cor pode ser aplicada pelo terminal/renderer sem alterar os 60 caracteres úteis de cada linha.

```text
+----------------------------------------------------------+
|  RRRR    AAA   FFFFF   AAAAA  EEEEE  L      III   AAAAA  |
|  R   R  A   A  F      A     A E      L       I   A     A |
|  RRRR   AAAAA  FFFF   AAAAAAA EEEE   L       I   AAAAAAA |
|  R  R   A   A  F      A     A E      L       I   A     A |
|  R   R  A   A  F      A     A EEEEE  LLLLL  III  A     A |
|                                                          |
|  GPU | NEON | CACHE L1/L2 | RAM | STORAGE | FAILSAFE     |
|  AUDIT + QUALITY + SECURITY + SIGMA + T7 + A42           |
+----------------------------------------------------------+
```

Exemplo com cor ANSI opcional para terminal compatível:

```text
\x1b[36m+----------------------------------------------------------+\x1b[0m
\x1b[32m|  RRRR    AAA   FFFFF   AAAAA  EEEEE  L      III   AAAAA  |\x1b[0m
\x1b[33m|  GPU | NEON | CACHE L1/L2 | RAM | STORAGE | FAILSAFE     |\x1b[0m
\x1b[35m+----------------------------------------------------------+\x1b[0m
```
