## Key Concepts

### E-Level Classification

Maturity scale from E0 (idea) to E5 (machine-proved):
- **E0:** Unimplemented
- **E1:** Implemented but untested
- **E2:** Basic testing framework exists
- **E3:** Functional testing (real-world data)
- **E4:** Independent verification
- **E5:** Machine-proved (formal verification)

### Gap Categories

- **VOID:** No artifact exists
- **PENDING:** Artifact exists but incomplete
- **AUDIT:** Implemented but needs verification
- **RUNTIME:** Only known at execution time
- **REFERENCE:** External specification

## Troubleshooting

### Gap Verification Fails

```bash
# Check which check failed
./tools/verify_all_gaps.sh

# Run specific gap with verbose output
./tools/verify_all_gaps.sh L3

# Check tool availability
which readelf    # for L3
which javac      # for L4
which d8         # for L4
```

### Proof Receipt Not Generated

```bash
# Check proofs directory
ls -la docs/proofs/

# Re-run tool with verbose output
./tools/validate_apk_elf_structure.sh out.apk

# Check permissions
chmod +x tools/*.sh
```

### Test Failures

```bash
# Run functional tests
./tests/test_e3_functional_phases_21_45.c    # Should be 42/42 pass
./tests/test_e2e_apk_pipeline.c              # Should be 22/22 pass

# Check test compilation
gcc -std=c99 -O2 -Wall -Wextra -ffreestanding -I. -IApkc \
    tests/test_e3_functional_phases_21_45.c -o test_phases && ./test_phases
```
