# Release v0.1.0-apkc-termux-arm32-proof

Data de corte: 2026-06-14

## Nome

`v0.1.0-apkc-termux-arm32-proof`

## Escopo

Esta release congela o primeiro estado funcional provado do ApkC:

> ApkC gerando, assinando, instalando e abrindo um APK Android mínimo no próprio Termux/Android ARM32.

## Prova executada

Ambiente observado:

```text
Termux / Android / ARM32 ARMv7l
Diretório: $HOME/RafPolimata-main/Apkc
Compilador: cc
Assinador: apksigner 33.0.1-1 via Termux
Pacote: com.rafael.teste
```

## Comando de compilação que funcionou

```sh
cc -std=c11 -Oz -Wno-unused-function \
  -nostartfiles -Wl,-e,_start \
  apkc.c -o out/apkc
```

## Comando de geração do APK

```sh
out/apkc hello.s.txt \
  -o out/hello.apk \
  -p com.rafael.teste \
  -l RafaelTeste \
  -n hello \
  -32
```

## Evidências observadas

### ZIP/APK

`unzip -l out/hello.apk` listou:

```text
lib/armeabi-v7a/libhello.so
AndroidManifest.xml
classes.dex
```

### Manifest AXML

`aapt dump xmltree out/hello.apk AndroidManifest.xml` confirmou:

```text
package="com.rafael.teste"
android.app.NativeActivity
android.app.lib_name="hello"
android.intent.action.MAIN
android.intent.category.LAUNCHER
```

### ELF ARM32

`readelf -h out/libhello.so` confirmou:

```text
Class: ELF32
Type: DYN (Shared object file)
Machine: ARM
```

`readelf -s out/libhello.so` confirmou símbolos:

```text
ANativeActivity_onCreate
android_main
```

### DEX SHA-1

Validação interna do `classes.dex`:

```text
header: 9ea7c00884bffbdbbab055ddc3ad6565050fc4e4

PASS
```

## Claim permitido

```text
ApkC gera no Termux/Android ARM32 um APK mínimo assinado, instalável e abrível no Android, contendo Manifest AXML válido, classes.dex com SHA-1 correto e libhello.so ARM32 válida com símbolos NativeActivity.
```

## Claim bloqueado

- Produção Play Store.
- Compatibilidade ampla de aparelhos/Android versions.
- ARM64 instalado/rodando.
- Execução útil interna da NativeActivity medida via logcat.
- `-nostdlib` puro no Termux ARM32 sem helpers internos.
- PR #19 como requisito para funcionamento básico.
